# 插件故障处理

先区分安装、配置、执行、结果与外部平台。保留原错误、时间和操作身份，当前独立验收范围见[状态](../status.md)。

| 现象 | 检查与处理 |
|---|---|
| 安装后无独立页面 | 按[选择表](../../README.md#选择插件)进入所属表面；专项和 provider 常嵌入脚本或目标编辑 |
| 版本/契约不匹配 | 核对配套 Host、插件来源和完整包；不手改指纹或复制 DLL |
| 选目录后无配置或结果串目录 | 核对实际安装根、程序、保存配置和候选；晚到旧结果不保存 |
| 原生编辑入口缺失 | 核对脚本已绑定编辑程序与资源、运行占用和权限，保留来源诊断 |
| BAAH 日志缺结果 | 核对文件日志开启、实际 log_*.txt 和当前任务范围；缺业务证据保持待核实 |
| BAAH 修复被拒绝 | 重新读取并预览当前候选，核对修订、权限与资源；上游自身设置也可启用文件日志 |
| OkNTE 只有启动器行为 | 停用相关日程，核对安装版本、当前日常入口和该次日志，记录最小复现 |
| 签到登录空白或失败 | 记录平台和加载阶段，在原窗口刷新/验证或取消；不以真实签到测试网络 |
| 保存/签到结果待确认 | 查询原操作；保留草稿，不创建新提交补偿 |
| 活动显示旧数据 | 查看最近成功时间、刷新状态和限频，失败时保留缓存 |
| 壁纸上传失败 | 检查格式、大小、数量和总配额，未知结果先查原操作 |
| 实时预览等待或不可用 | 核对当前任务、目标、窗口/ADB 和权限，保持 run/attempt 一致 |
| 模拟器实例歧义 | 选择准确安装和实例；不按名字批量终止 |
| Maa 可预览但不可运行 | 处理明确的控制器、资源、程序映射与阻断诊断 |

## 提供材料

提供 Host/插件/上游版本、构建或包身份、最小步骤、预期与实际结果、脱敏错误及操作/任务 ID。只附必要截图或日志，移除凭据、Cookie、Token、密码和验证码。

运行中问题先请求停止并等待进程结束和配置恢复；未知状态保留原目录与日志。操作说明见[用户入口](README.md)，开发定位见[任务地图](../agents/README.md)及[验证指南](../development/validation.md)。
