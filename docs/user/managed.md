# 通用插件使用

安装与启用见[用户入口](README.md)。这里说明每个插件的实际任务入口；完整客户端中的状态，以所用候选的验证记录为准。

## CustomWallpaper

**用途与前提：**设置应用背景、轮换和显示效果。准备 PNG、JPEG 或 WebP 图片；当前配额为最多 32 张、单张 8 MiB、合计 256 MiB。

**入口：**应用设置中的“自定义壁纸”。

**第一次使用：**上传一张图片并选用，开启“启用自定义壁纸”，调整模糊、变暗和透明度。确认同一实例其他页面能看到保存后的效果，再按需增加图片、排序和轮换。设置即时保存，并同步到连接该实例的浏览器。

“透明度运用于非主页面”控制二级表面的透明效果。启动轮换由实际桌面启动会话决定；不要把打开另一个浏览器页签理解为一次新的桌面启动。

**失败与取消：**图片超限或解码失败时换用有效图片；保存结果待确认时先核对原操作，不重复上传。删除图片前确认选择；与其他保存文档仍有关联的图片不能被意外回收。

**设置行为：**与内建设置共用分类展开和公共开关集合，选择与效果即时保存。参考[源码使用说明](../../plugins/managed/custom-wallpaper/README.md)。

## EmulatorSupport

**用途与前提：**为 Android 脚本提供雷电、夜神和 BlueStacks 的发现与实例控制。先正常安装并配置需要的厂商模拟器。

**入口：**支持 Android 的脚本或账号绑定中的目标选择；本插件没有独立的日常任务页面。Generic ADB、MuMuManager 和应用目标识别由 Host 提供，不因安装本插件自动变为三家厂商能力。

**第一次使用：**选择实际安装及实例，核对实例身份和 ADB 设备，运行一个受控目标准备流程。关闭时确认只关闭所选实例，其他实例应保持原状。

**失败与取消：**多个安装、同名实例或端口冲突时，补充明确选择，不默认取第一个。无法确认目标时停止该次动作，先处理厂商配置；不要按进程名批量结束模拟器。

**支持范围：**受控库存与 CLI 接线证据不代表本机所有真实厂商版本都已验证。第一次使用某厂商时只验证这一个安装与实例，不额外安装其他厂商来凑测试矩阵。参考[项目说明](../projects/emulator-support.md)。

## GameActivities

**用途与前提：**在概览查看活动、倒计时与详情。初始不订阅游戏；可选八款游戏，活动源共 11 份，但蔚蓝档案和异环各只选一个内容进度/区服来源。

| 游戏 | 来源选择 |
|---|---|
| 蔚蓝档案 | 国服、日服、国际服 |
| 原神 | 当前支持来源 |
| 明日方舟：终末地 | 当前支持来源 |
| 星塔旅人 | 当前支持来源 |
| 崩坏：星穹铁道 | 当前支持来源 |
| 鸣潮 | 当前支持来源 |
| 绝区零 | 当前支持来源 |
| 异环 | 当前支持的两份来源 |

**入口与操作：**在概览活动卡片打开活动设置，选择游戏与正确内容进度，再按需排序和设置轮播。调整即时生效，取消还原本次打开前的设置，保存与关闭保持当前值；未订阅游戏的内容进度保留。

**第一次验证：**确认订阅项、时间和详情正确；手动刷新后检查数据时间。文字内容不应等图片完成才能显示。时间按浏览器所在电脑时区展示；无法核实的时间保留原值并提示。

**常见失败：**失败时可能继续显示最近成功缓存，请查看数据状态，不把缓存当作刚刷新成功。手动刷新有 60 秒间隔，连续点击不会提高更新速度。成功返回空列表应清除旧活动，网络失败应保留旧内容。

**刷新行为：**多个到期来源有界并发，保留同源单飞、迟到结果拒绝与缓存规则；刷新失败显示当前状态。参考[游戏活动](../projects/game-activities.md)。

## GameCheckIn

**用途与前提：**为六个平台的 14 个区域游戏组合建立签到任务。使用自己的有效账号凭据；任务、计划、结果和通知分别查看。

**入口：**“游戏签到”页面。先建一个任务和一个游戏，不立即启用多条计划。

**第一次验证：**保存任务后确认平台、游戏、凭据状态和计划；实际签到前确认这是你要执行的任务。结果待确认时先读该次记录，不再次提交。完整步骤和登录问题见[签到专页](game-checkin.md)。

## LiveScreenshot

**用途与前提：**显示当前任务已绑定的游戏窗口或 Android 画面。需要有实际正在运行且已准备好的目标；它不自行启动游戏，也不抓取任意桌面。

**入口：**正在运行的任务详情/预览区域。

**第一次验证：**运行一个已配置的受控任务，打开其画面，确认来源与该次任务一致；切到另一个任务后不应继续显示前一个任务的画面。可见时约每五秒采样，慢请求会跳过节拍。

**失败与取消：**“等待游戏”“等待模拟器”“窗口未就绪”先检查目标准备状态；权限拒绝、身份变化或解码错误按错误处理，不靠重启任务清除。隐藏或离开页面后停止预览请求。

**范围：**预览保持比例、最高 360 像素高，小图不放大；历史原图仍保留其自身用途与尺寸。参考[实时截图说明](../../plugins/managed/live-screenshot/README.md)。

## MaaFramework

**用途与前提：**直接读取受支持的 MaaFramework Project Interface 项目，编辑选择并由独立执行引擎运行。先准备已有项目、配置和资源；支持范围包含 MXU、MFA、CFA、MaaPiCli 来源映射，但具体控制器和真实项目组合仍需分别确认。

**入口与操作：**添加框架直驱脚本，选择项目根，读取来源；在脚本及账号绑定编辑区核对 Controller、Resource、任务顺序、次数和参数。需要程序/解释器或附加文件时，使用实际项目的明确映射。先预览，再保存；预览不是执行。

**第一次验证：**保存后重新打开，确认选择没有串到其他账号，再对一个明确支持的本机目标执行受控任务。初始化只做项目声明的准备步骤；不要把初始化成功当作游戏任务成功。

**失败与取消：**未知保存结果先查询原操作。关闭或隐藏编辑器保留输入，秘密在专用内存中保留且重开默认遮罩；明确取消或结束界面会话时清除。项目被阻断时可以查看已解析信息，但不能强行运行。运行失败或取消后，等待独立执行进程结束，再进行配置恢复。

**与两个专项的区别：**MaaEnd、MaaStellaSora 专项调用用户安装的上游程序；框架直驱提供独立编译与执行路径。两种接入方式分别选择，不要求为两个专项安装本驱动。参考[Maa 项目说明](../projects/maa-framework.md)。
