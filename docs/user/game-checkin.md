# 游戏签到：账号、计划与结果

本页适用于本地候选的游戏签到插件。官方页面登录的直接白屏原因尚未确定；失败后留窗继续的旧版流程正在恢复。相关状态见[已知差异](README.md#本地候选的已知差异)，不要把文档更新理解为登录问题已经修复。

## 支持哪些平台

| 平台 | 当前游戏范围 |
|---|---|
| 米游社 | 原神、崩坏：星穹铁道、绝区零、崩坏 3 国服 |
| HoYoLAB | 对应四款国际服 |
| 森空岛 | 明日方舟、明日方舟：终末地 |
| SKPORT | 明日方舟：终末地国际服 |
| 库街区 | 鸣潮、战双帕弥什 |
| 塔吉多 | 异环 |

这是六个平台、14 个区域游戏组合。不同平台的凭据不能相互替代；选择游戏时同时核对区服。当前功能不包含社区币、分享、云游戏或付费补签。

## 建立第一个任务

1. 打开“游戏签到”，添加任务，输入能辨认账号和用途的名称。
2. 选择一个平台及需要签到的游戏，核对区服。
3. 使用当前客户端支持的登录方式取得凭据，或填写自己已有的有效凭据。
4. 先保存，不必立即增加多条计划。重新打开后“已配置”表示已有保存值，空输入框不代表凭据丢失。
5. 需要立即签到时，主动选择“立即运行”并查看该次运行记录。确认结果后再安排日程。

## 登录与凭据

五个平台提供官方网页登录；塔吉多使用其原生登录流程。网页登录是否可用取决于当前客户端是否具备实际捕获能力，远程浏览器不能靠修改地址获得本地能力；没有相应能力时保留手填。

已保存凭据有三种明确操作：

| 操作 | 保存后的含义 |
|---|---|
| 保留 | 继续使用现有值；不需要重新填写 |
| 输入新值 | 用本次明确输入替换 |
| 清除 | 保存时清除已保存值 |

打开编辑器不会自动展示秘密。支持临时查看的本地客户端中，需要你点击眼睛并确认后才能读取；关闭或隐藏编辑器会清除已显示的明文。不要把凭据、Cookie、Token、密码或验证码放到截图、普通备注或诊断日志中。

网页登录成功后仍需保存任务，候选凭据才成为任务配置。取消登录不保存新凭据。登录失败时保留普通任务草稿；本轮目标是在会话仍有效时恢复原窗口内刷新、继续登录和重试，不强迫重新填写整个任务。

### 网页不加载或登录失败

先确认官方页面在当前网络可达，记录出现问题的平台、是否打开窗口、是否开始加载及脱敏错误。不要反复发送验证码或触发真实签到来验证登录。

本轮尚未把白屏归因于 URL 或普通 30 秒请求超时。开发者应区分窗口创建、登录初始化、页面加载、子页面拦截和账号验证几个阶段。用户可以取消该次登录，保留普通草稿；有有效凭据且界面允许时可手填。开发定位见[前端开发](../developer/frontend.md#登录失败与白屏的最小诊断)。

## 设置计划和通知

任务可以没有计划，仅手动运行。添加定时后核对执行星期、本机时区和时间，并确认任务与计划都已启用。软件关闭期间错过的时间不会自动补跑。需要多账号或多任务时，保持名称能区分，先避免重复日程。

通知目标来自 Host 已配置的通知任务。选择需要的目标并启用通知；不选则不发送。通知“已受理”不等于平台一定送达。通知失败不会把已经完成的签到回滚，也不应重新签到来补发通知。

## 如何理解结果

- **全部成功：**所选游戏的结果已确认。仍可进入运行记录查看逐游戏结果。
- **部分成功或全部失败：**查看具体游戏和原因，不用总结果覆盖单项失败。
- **结果待确认：**提交可能已发生，本地尚不能确定；先读取该次结果或等待可验证核对，不立即再次提交。
- **运行中：**等待当前任务结束。编辑或删除也必须等待相关运行状态允许。

保存结果待确认时使用“检查保存结果”，保留原草稿。重新新建一个相同任务不是恢复原保存操作的方法。

## 首次使用完成的判断

平台、区服、凭据状态与计划均与意图一致；一次主动操作能查看正确账号的记录；取消编辑不改已保存任务；未知结果不会自动重复提交。真实账号登录和签到由用户选择执行，开发组件测试不会替你完成这些操作。

完整技术范围与固定协议记录见[项目参考](../projects/game-checkin.md)。
