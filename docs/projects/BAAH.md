# BAAH 项目适配

公共契约见[任务协议](../author/TASK_PROTOCOL.md)。本适配器使用 0.2.0 / daily-flow-v1，最低 Host 0.16.15。

发现以活动流水线、任务序号和名称作身份，TASK_ONOFF 平行数组以完整 TASK_PIPELINE 为 guard。自动登录和收尾独立建模，不进入业务分母。选择重试映射只取流水线任务，不能把自动登录的数组位置误用于 TASK_ONOFF。

Task.run 的前置、执行、后置和结束日志构成嵌套范围。当前 pipeline 顺序用于区分同类任务；缺口、source/epoch 改变或 pipeline 冲突使原范围失效。正常闭环且无未恢复业务错误即完成，不要求每个点击另有业务凭证。前置失败/超时、后置失败/超时保持失败，返回主页和普通结束不能清除失败。明确正常条件跳过另计 skipped。

致命异常由 BAAH_main 捕获后可能内部重跑。先保留失败事实；明确错误自动关闭或 Host 进程退出后，只有顺序已确认的后续任务可记为未执行。新的 pipeline 启动和执行序号证明恢复，正常展示最终只显示完成，历史保留原证据。

日常购买 AP、扫荡等失败参与有限重试；保留用户价格、次数及消费额度。CURRENT_PERIOD_TASK_INDEX 属于 sessiondict，独立进程经 MyConfig.parse_user_config 初始化，不用写持久进度实现重试。Host 使用原有 CAS/journal 恢复平行选择数组和账号快照。

TARGET_EMULATOR_PATH、TARGET_IP_PATH、TARGET_PORT 从当前绑定用户主配置解析；software-config 仅提供 SAVE_LOG_TO_FILE。缺省 IP/port 为 127.0.0.1/5555，显式错误类型不当成缺省。直接 ADB 序列号不能证明与 Host 网络端点相同，仍保留诊断。关闭文件日志时阻断，不以 stdout 可用代替。

生产源位于 adapters/task-protocol/baah。

## 启动与日志配置门禁

文件日志设置 `SAVE_LOG_TO_FILE` 必须为布尔 true。关闭“是否输出日志到 /DATA/LOGS/ 目录”会阻断配置检查，即使标准输出可用也不能代替文件日志；缺失资源或非法值同样阻断。PC 启动由 BAAH 启动器链路负责，Host 的直接启动选项禁用；模拟器模式继续使用原有启动责任。

## 配置修复

- 游戏路径：主快照 `TARGET_EMULATOR_PATH`，PC 模式绑定游戏路径。
- 完成动作：非空 `POST_COMMAND` 清空；三个退出游戏/模拟器/程序开关保留。
- 启动任务：非 MAA，无插入任务。

仅对已保存的当前用户快照逐项预览、确认和备份。字段类型错误不猜测转换；生成的 `data/editor.js` 提供修复策略；详细事务及不适用边界见 [配置编辑契约](../author/CONFIG_EDITOR.md) 与 [八专项覆盖表](../frameworks/COMPLETION_ACTIONS.md)。

软件设置修复：附加快照 `software_config.json/SAVE_LOG_TO_FILE` 缺失或为 false 时可预览设为 true，对应“是否输出日志到 /DATA/LOGS/ 目录”。已开启不重复建议，其他类型不猜测转换；应用到当前用户快照，下一次编辑/运行由配置交换使用。
