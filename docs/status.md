当前源码目标为 Host 0.18 系列、公共 SDK 0.1.0 与插件 0.5.0。实际源码/包身份及历史运行结果保存在对应回执，当前行为由[主题和项目参考](README.md)维护。本页只列仍需独立完成的资格。

| 范围 | 完成条件 |
|---|---|
| 八个专项真实发行程序 | 以明确发行安装、隔离配置和对应游戏环境核对入口、配置消费、取消、恢复和结果 |
| 雷电、夜神与 BlueStacks 实际安装 | 对各已安装厂商分别核对 CLI、ADB、截图和关闭；受控输出保留组件范围 |

| 真实账号与外部通知 | 在对应授权和环境中核对平台登录、签到、角色结果与通知送达；未知提交只读对账 |
| SDK 运行矩阵 | 按实际任务补运行消费者与生命周期，compile-only 回执维持其原范围 |
| 完整环境体验 | DPI、多屏、长期导航和整机资源回落按 Host 产品验收记录 |
| 正式发行 | Production 信任、原候选、受保护检查及 Publisher 按[发行流程](operations/release.md)和明确授权闭环 |
