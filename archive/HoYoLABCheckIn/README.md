# HoYoLAB 自动签到

这是一个 NexusPipeline `managed-code` 插件。插件在用户脚本实际开始运行时检查该用户当天尚未成功的游戏，并执行一次签到；没有用户运行时不会触发签到。

用户设置包含启用开关、完整 HoYoLAB Cookie 和游戏选择。Cookie 通过 Plugin API 用户密钥存储加密保存，插件配置记录每个游戏的最近尝试日期、成功日期与结果。

插件使用 Plugin API v1.2 的声明式用户全局管理、用户列表徽章、用户运行事件、用户数据和宿主 HTTP 出口。用户列表显示一个聚合签到徽章；签到失败只产生插件通知，不影响脚本执行、运行记录或调度计划。
