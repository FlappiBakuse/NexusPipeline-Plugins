# 更新日志

## 0.5.0

- 未编辑的表单关闭后不保留草稿；黄色字段提示仅在重新打开有修改的草稿后显示。

- 重新打开未保存的任务或登录草稿时显示提醒；已有任务中修改的字段和开关以黄色标记，改回原值后清除。

- 签到页面按状态事件同步，稳定数据复用状态版本；隐藏和关闭时停止订阅与请求。

- 签到任务采用独立圆角卡片与紧凑行距，图标、文字组与操作保持垂直居中；页面仅保留主标题和说明。

- 网页登录先在原窗口验证候选凭据，验证失败可继续登录或刷新，验证成功且清理完成后返回草稿。

- 实现六平台 14 个区域游戏组合、多任务计划、即时执行、逐游戏结果与 Host 持久副作用门禁适配。
- 使用当前客户端私有凭据草稿、六字段原子保存、任务 quiescence 和精确历史写者证明。
- 提供生产前端及正式操作权限/操作 ID、只读登录可用性与实际登录授权的独立边界。
- 正式入口接入业务服务与独立页面；五平台官方隔离捕获使用独立登录来源、完整条件组、当前账号验证和取消排空；完整安装资格仍待验证，未执行真实账号签到。
- 已保存凭据默认 keep 和空草稿；仅支持的客户端显式确认后读取，取消确认和远程手填均不发送揭示请求。
- 编辑器保留 SDK Surface 的原型方法和实时可见性，正确处理隐藏、恢复及取消清理。
- 行级语言订阅随行释放；恢复工作日09:00定时和中英文平台名称，停用任务可保留空游戏选择。
- 复用已校验快照，并以任务 ID 字典关联宿主事实，避免重复全量验证和嵌套扫描。
