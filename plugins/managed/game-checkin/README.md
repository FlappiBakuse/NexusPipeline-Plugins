# GameCheckIn 0.5.0

管理米游社、HoYoLAB、森空岛、SKPORT、库街区和塔吉多的游戏签到，支持多任务、定时计划、运行记录和结果通知。

目标 Host 0.18.0 / SDK 0.1.0。源码包含六平台 14 个区域游戏组合、多任务与星期计划、六字段凭据 keep/set/clear 原子保存、Host 手动执行与计划 handler、运行历史和逐游戏结果、通知目标及生产前端。

平台请求必须经 Host 持久 effect 门禁；Busy 不发请求，Unknown 仅作可验证的只读对账。塔吉多新 claim 后刷新并原子保存，保存未知立即停止。任务修改与删除持有 Host quiescence。秘密草稿由 Host ClientId/ClientLifetime 与 activation 隔离，普通文档和日志不保存秘密。已保存凭据打开编辑器时保持 keep 和空草稿；仅支持揭示的客户端在点击眼睛并明确确认后才读取，远程手填不请求揭示。

纯业务和正式 SDK 适配使用模拟凭据及受控 HTTP 验证；生产前端及正式 SDK 已通过实际 Edge 的受控回归。这些组件证据不代表实际平台登录、签到或安装通过。

正式入口注册 `checkin` 业务 provider，并提供独立页面。五平台官方网页登录通过 Host 隔离捕获，独立声明固定登录来源与 interactive-login 权限；同域完整凭据组通过字符/相等约束及当前账号验证后才进入草稿。取消和 scope 停止等待窗口/会话清理。没有实际 Desktop 捕获能力时保留手填；塔吉多登录仍需当前客户端的真实 native 资格。通知队列受理不代表外部送达。原包及完整软件资格分别记录，当前不能将组件验证视为全部 P3 业务完成。

编辑器显式代理全部 SDK Surface 成员，方法绑定原 surface，可见性始终读取当前 getter；编辑器取消信号仅合并原 signal，不丢失原型成员。隐藏时清除凭据草稿，取消时释放自身订阅。

网页登录先在原窗口验证候选凭据，验证失败可继续登录或刷新，验证成功且清理完成后返回草稿。

签到列表使用紧凑卡片，图标、名称与状态、操作按钮垂直居中；备注和状态换行时自动增加高度。
