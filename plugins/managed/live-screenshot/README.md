# LiveScreenshot

LiveScreenshot 0.5.0 在运行任务详情中展示当前游戏或模拟器画面。
安装并启用后打开正在执行的任务。它使用 Host 已绑定的 run/attempt，不自行启动游戏，也不任意抓取桌面。

可见时每五秒采样，慢请求跳过节拍，不积压。隐藏、离开任务、取消、停用或卸载后停止展示请求并释放图片。
预览等比缩小到最高 360 像素高，小图不放大；历史截图和其他原始图像用途保持原尺寸。
最近更新时间来自 Host 采集完成时间，不是浏览器收到图片的时间。

等待游戏表示目标准备中；窗口未就绪表示尚无可用画面；等待模拟器表示 Android 目标准备中。
暂不可用时先核对目标和程序状态。权限拒绝、身份变化、断连或解码错误仍报告失败，不用反复启动任务绕过。
并发任务分别持有预览，新 attempt 不沿用旧画面。

需要对应 Host 后端与真实目标环境。受控原生窗口或 Android provider 测试不证明全部厂商已验证，
缺少实际厂商安装的验证单独记录。
公开 provider 为 current-task。采集进程、身份验证、取消和回收由 Host 负责。
浏览器使用 FrontendTransport.preview 状态联合类型，ready 分支的图片租约必须释放。
