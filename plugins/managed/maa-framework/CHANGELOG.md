# 更新记录

## 0.5.0

- 仅保留实际修改的编辑草稿，重开显示保存或取消提醒；已有对象仅在恢复后标记变化字段，首次编辑与新建对象使用普通状态。成功保存更新基线，取消及会话结束清理所属草稿。
- 严格解析原生/程序事实、只读来源和观察检查点，并将选中任务绑定到冻结的启用 occurrence。
- 接通通用 Maa 框架直驱的实例创建、项目编译、受限任务适配与原 worker 执行链。

- 增加独立 worker 入口，通过原 Host 通道消费完整冻结项目、选中 occurrence 和私有工作目录；逐文件物化资源并持有只读租约，目标操作只经 Host 认证通道。
- 锁定官方 MaaFramework 运行库发行与归档摘要；打包器验证完整 worker 与十个原生 DLL 闭包，缺少输入证据时拒绝生成包。
- 通过 Host 冻结的 executionTaskId 映射业务 ID；排空后发布绑定原执行身份、项目指纹、重复序号与原生 task ID 的结果事实。

- 增加独立 worker 原生任务会话，按冻结 occurrence 顺序与重复次数提交，控制回调仅经 typed port；取消先排空，无法证明停止则保留全部 native/输入所有权。
- 拒绝原生 plugins 自动旁加载与 Command；截图默认拒绝，仅在可信内部输出 scope 下以严格路径/参数门禁保留原生 Screencap，停止后固定私有输出及覆盖可能，外层仍须证明完整进程族停止。
- 关闭可能记录原 pipeline 的原生日志；实际输出 scope、target/IPC/Agent 仍需 Host 组合。
- 提供冻结内存 PI v2 编译和 MXU、MFA、CFA、MaaPiCli 四类保存配置映射，保留来源身份、重复任务、选项和完整 import。
- 按各客户端规则解释继承、选项合并、预设和有界技术等待，拒绝无法保持语义的外部动作及未绑定密码。
- 将完整 PI 页图、导入配置、来源读集合和语义计划绑定为私有编译 bundle，提供保留重复身份与精确内容引用的 256 KiB 有界执行投影。
- 通过正式 SDK 注册 project compiler，仅经 Host 所选只读来源发现和编译，返回完整闭合资产 DAG，绑定目录与缺失观察。
- Compile 验证 Host 已保存配置 mount、实例与完整继承依赖，并绑定修订/契约/快照事实；声明按语义顺序去重的资源树供 Host 独立归档。
- 业务设置阻断时保留完整只读资产与 blocking diagnostics，明确禁止执行；补充原始行位置、继承来源及原文件 SHA 绑定，源码/身份/预算错误仍拒绝。
- 扩展激活只注册编译器，任务会话由独立 worker 持有；初始化发布、Agent 和完整设备组合仍待验证。
- 提供绑定冻结编译的独立 editor-index/分页公开子图，保留完整已知编辑 schema、任务身份和阻断诊断，隔离原配置、已保存输入、密码与未知敏感扩展。
- 通过实际绑定表面和宿主鉴权项目入口接入来源发现、明确实例选择、CAS 保存和有界预览，关闭或变更草稿时释放旧预览。
