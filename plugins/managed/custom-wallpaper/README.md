# 自定义壁纸

为应用设置自定义背景，支持图片列表、定时轮换、启动轮换、模糊、亮度和透明度调整。

目标版本 0.5.0，使用 NexusPipeline 0.18.0 与公共 SDK 0.1.0。

插件使用现有壁纸设置和应用外观表面。普通设置、图片原字节及完整引用集合通过 Host 的同一文档 CAS 保存；图片按原字节摘要去重，每插件最多 32 张、单张最多 8 MiB、总量最多 256 MiB。取消传输或保存失败不能发布未提交的图片引用；已经提交而响应丢失的操作需要核对结果，不能自动重复保存。

支持 PNG、JPEG、WebP，浏览器上传前解码检查；Host 核对容器格式、尺寸、摘要和配额。保存支持当前图片、排序、定时轮换、启动轮换、模糊、变暗以及 0%–50% 卡片和侧栏透明度。原生桌面握手产生唯一会话身份；本机浏览器或远程页面不能产生新的启动轮换次数。

Host 在同一事务中处理图片退役，仍被其他保存文档引用的原图继续保留。无法识别的图片字节会阻断退役，保留原数据。浅色、深色及系统主题沿用应用外观选择；关闭“透明度运用于非主页面”会让二级表面使用不透明背景。

源码编译与浏览器类型检查已通过。实际安装、容量、轮换和浏览器业务验收以对应运行回执为准；不由编译成功推定全部业务通过。

设置使用公共折叠卡与开关集合，分类展开由宿主统一管理。

设置分类按钮将壁纸卡片置顶并展开，再次点击收回并恢复顺序；卡片标题在当前位置切换展开。标题下显示壁纸、轮换和效果说明，展开与收回均有动画，并遵循系统减少动态效果设置。
