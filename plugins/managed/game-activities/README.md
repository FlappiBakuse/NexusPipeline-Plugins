# 游戏活动

活动设置即时生效；取消还原本次打开前的设置，保存和关闭保持当前值；丢失响应只读核对原提交。

在概览中查看订阅游戏的活动日程，支持游戏排序和内容进度设置。

版本 0.5.0，要求 NexusPipeline 0.18.0 与 SDK 0.1.0。

从 SRA 公共活动 API 显示八款游戏的 11 份活动源。初始不订阅任何游戏；设置保存完整游戏顺序，以及蔚蓝档案、异环的内容进度，未订阅游戏的进度也会保留。设置取消不写入，保存使用宿主文档修订号 CAS。

文字数据每六小时自动检查，在可核实时间边界附近增加检查；手动刷新至少间隔 60 秒。成功的空列表会清除旧活动，失败保留最近成功数据并退避。切换订阅或停止插件会取消旧工作，迟到响应不能发布。初始化由 scope 拥有的唯一任务等待宿主安装发布完成后读取文档；所有前端调用等待该任务，后台刷新不继承短期前端调用权限。普通缓存与设置保存在宿主 Documents；未知保存格式保留原字节并拒绝覆盖。

11 个已登记来源的无偏移时间按 UTC+8 解释，原文的明确 UTC 或偏移优先；未登记来源的无时区时间仍显示“时间待核验”和原值。已核实时间按浏览器所在电脑时区显示并参与倒计时和分组。已结束活动默认折叠，详情不提供抽卡与公告跳转。

封面只接受活动 JSON 实际引用、且属于 manifest 中八个精确 HTTPS 来源的 URL。前端仅传不透明封面 ID，通过宿主鉴权图片端口读取；文字无需等待图片。插件内存图片缓存限制为 32 MiB / 128 项、单项 8 MiB，正常图片 30 分钟过期，失败短暂缓存。停止后释放内存图片和请求，保留用户设置及普通缓存。

成功封面同时写入宿主图片库，重启后可在离线时复用。封面 URL 身份与图片内容摘要通过 `cover-cache` 文档关联，文档与引用原子提交；最多 32 个封面、合计 32 MiB，超过限制淘汰最早保存项。内容源不再引用的封面在下一次写入时移除，宿主回收失去引用的图片。读取仍要求当前订阅内容引用该封面，未知缓存格式保留原字节。

前端通过生产 `createFrontend` 使用 SDK transport，兼容远程 HTTP 会话；无浏览器直接网络或文件旁路。安装包编译、业务组件、浏览器夹具和完整 Host 安装验收属于独立验证层。当前状态见仓库 `docs/projects/game-activities.md`。

活动文字源最多四个并发刷新，保留逐源结果、订阅代次和手动刷新节流。

手动刷新会重新读取失败的图片，保留已加载图片缓存；未提供封面时显示背景。活动工具按钮的图标与悬停区域居中对齐。

切换页面保留当前订阅封面的浏览器内存 URL，返回概览立即显示。仅取消未完成请求；封面标识变化、取消订阅或卸载表面时释放对应资源。左右翻页使用细长 SVG 箭头。
