# 更新记录

## 0.5.0

- 活动状态按订阅变化刷新，初始化只读取已选活动源；复用未到期缓存，避免无变化轮询。

- 切页立即复用已加载封面；左右翻页使用细长 SVG 图标。

- 手动刷新重试失败封面，补齐已核实图片来源；无封面时保留背景，工具按钮图标居中。

- 活动文字源最多四个并发刷新，保留逐源结果、订阅代次和手动刷新节流。

- 提供 SRA 八游戏、11 活动源与完整订阅顺序、蔚蓝档案和异环内容进度设置。
- 通过宿主 Documents、Http 和前端 transport 接入持久缓存、CAS 保存、自动与限频手动刷新。
- 11 个已知活动源的无偏移时间按 UTC+8 解释，显式偏移优先；未知来源仍保持未知，按电脑时区显示已核实时间；图片失败保留文字与最近成功数据。
- 对封面来源、响应大小、内存缓存与插件停止进行有界处理。
- 封面网络请求在短锁外执行，最多四个缓存未命中请求并行；过期代次不发布结果。
