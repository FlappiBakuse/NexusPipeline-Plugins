# Changelog

## 0.5.0

- Implement vendor-specific discovery, selection, control arguments and bounded session policies for LDPlayer, Nox and BlueStacks.
- Bind installation, tool, original configuration and device identities; reject ambiguous installations, changed inputs and unproven process ownership.
- Register vendor providers through the fixed SDK with Host-owned publication, revocation and callback draining; keep CLI, ADB, media and cancellation outcomes explicit.
