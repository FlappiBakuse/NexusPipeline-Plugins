# 终末地小助手

将 终末地小助手 接入 NexusPipeline 的用户绑定、队列、计划和运行历史。插件不包含上游软件或游戏，需要先自行安装。

当前版本 0.4.5，需要 NexusPipeline 0.17.4 或更高的兼容版本，运行环境为 Windows 11 x64。

## 开始使用

1. 安装上游软件，并先在它自己的界面确认能正常配置和运行。
2. 在 NexusPipeline 插件页面安装并启用本插件，按提示重启。
3. 新建脚本，选择本插件，并定位包含 `MaaEnd.exe` 的安装目录。先在 MaaEnd 中完成设备、资源和任务配置，选择包含 MaaEnd.exe 的根目录。
4. 创建或选择用户，绑定脚本并编辑该用户配置。核对预览后加入队列，先手动运行，再设置计划。

## 使用范围

沿用 MaaEnd 自身界面与配置，支持模拟器。PC 游戏由 MaaEnd 的“启动游戏”前置任务通过启动器启动，宿主不直接启动游戏。请使用 MaaEnd v2.33.0 或更新的兼容版本，在自动执行实例中启用该前置任务，选择区服，并配置自动查找启动器或手动填写 `Launcher.exe`。

每个 NexusPipeline 用户使用独立配置快照。复制配置不等于切换游戏账号，运行前仍需核对游戏当前登录账号。任务结果与重试取决于已支持的任务及其有效完成证据，未知任务保持未核验；实际执行正常结束且已知任务无失败时，整体结果为 Success，并说明未核验范围。已知任务缺少必要证据仍按失败处理。

## 常见问题

无法识别安装目录时，确认已完成上游安装、目录中存在上述程序且没有正在更新。配置或运行准入提示不兼容时，按提示检查版本、目录及任务选择，不要绕过校验或在运行中替换配置。

上游升级后请重新核对绑定与预览。支持的任务、配置及版本限制见 [项目支持说明](https://github.com/FlappiBakuse/NexusPipeline-Plugins/blob/main/docs/projects/maa-end.md)；发行发现或打包成功不等于全部真实游戏任务已验证。

任务重试保留原启用的未知项、准备与收尾，原禁用项保持禁用；不重置额度、日期或上游进度。版本前进和无关配置字段不会单独阻断运行。
