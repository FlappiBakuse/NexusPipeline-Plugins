将 BetterGI 的原神「一条龙」接入 NexusPipeline，让不同账号使用各自的一条龙配置，并查看每次执行结果。

## 开始使用

1. 在 BetterGI 中设置游戏路径，保存一条龙配置和任务顺序，然后退出 BetterGI。
2. 在「脚本库」新建 BetterGI 专项脚本实例，选择 BetterGI 的安装目录。
3. 在「账号与配置」绑定脚本，通过「编辑配置」核对一条龙名称及来源。遇到同名配置时，先按路径选择，再在 BetterGI 中为本方案设置唯一名称后保存。保存后，在「任务计划」检查启用状态和任务顺序。

编辑或运行前，请退出当前 Windows 会话中已打开的 BetterGI，包括从其他安装目录打开的窗口。启动名称与其他方案重复时，本次运行会暂停，修改为唯一名称后即可重新运行。

运行结果以一条龙任务组的实际日志为准。结果缺失时，检查所选配置和本次日志；自定义脚本的内部动作请在 BetterGI 中核实。
