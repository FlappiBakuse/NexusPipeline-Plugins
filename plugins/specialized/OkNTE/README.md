# OkNTE

初始开发版本 `0.1.0`。仅日常单账号入口；每个 Nexus 用户使用独立配置快照。复制配置不会切换游戏登录账号。

已核查官方 Global v1.3.19 完整安装包的目录、日常源码和内嵌框架；关键文件与源码锁及 ok-script 2.0.4 一致。经用户授权的隔离管理员测试已验证官方启动器向包内 Python 3.12.10 `pythonw.exe` 转发参数及工作目录；解释器保护在业务代码前退出，不算真实日常验收。

运行前只读核对 `app.json`、更新仓库 detached HEAD 及 v1.3.19 的独立 tag ref，要求 Global、已安装、更新空闲且版本身份完全匹配；缺失、升级中、其他版本、运行中及不支持的仓库布局均阻断，不替用户修改安装文件。实测首次启动曾在 `-u manual` 下强制升级到 v1.3.20，因此手动更新参数不是版本锁。该检查不能消除检查后远端 tag 被移动或外部进程更新的竞争；此项及真实日常生命周期仍待发行资格验证。

布局为启动器根目录下 `data/apps/ok-nte/working/`，配置为 `configs`，框架日志为 `logs/ok-script.log`。候选入口参数固定为 `-a true -u manual -t 2 -e`：自动开始、手动更新、选择日常；不可改成任意任务或多账号任务。注册顺序与参数须在版本升级后重新核查。

外层完成只结束日常范围；内部明确失败不会被覆盖。未知和缺少成功证据的步骤保留检测限制。选择性重试只在已证明安全且配置可完整选择时执行，其他情况停止。
