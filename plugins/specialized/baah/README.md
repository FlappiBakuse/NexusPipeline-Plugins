# BAAH

将碧蓝档案小助手接入任务管理，读取所选配置的任务，跟踪执行结果并支持失败任务重试。

目标版本 0.5.0，固定 BAAH2.5.1。`upstream.json` 保存官方发行、完整 commit/tree 和资产身份。

四阶段适配使用选中用户资源 `main` 与附加 `software-config`，保留活动流水线、重复类任务的序位、自动登录与收尾身份。34 个既有任务范围分别映射当前 TaskInstanceMap；技术与收尾不进入业务分母。未知名称与开关保留原样并显示警告；存在启用未知项时，已知业务任务不授予安全重试资格。任务标题包含自动登录与收尾的中英文文本，随计划冻结供卸载后历史读取。

日志只接受主声明文件流 file:0 的当前版本 MyLogger 信封。Task.run 的前置、执行、后置与结束共同组成闭环；前后置失败、价格不可读、入口失败不能被返回主页或最终横幅覆盖。无红点与价格超限保留 satisfied/inapplicable 语义。明确的新 pipeline 与完整重执行可证明恢复，历史失败保留于本轮 checkpoint。

配置只返回完整绑定 operation、资源摘要和修订的 CAS 提案。文件日志为 false 时提议启用；非空 POST_COMMAND 提议清空；原退出标志、价格、次数、未知项及其他用户配置保持原值。手工意图支持当前流水线开关、活动流水线、已声明标量参数和启动目标；不写 sessiondict 进度。

选择重试仅包含明确失败的已选业务任务，自定义任务的未知外部副作用不自动重放。流水线中显式登录任务保留技术角色；失败业务声明此前启用的登录为安全重试前置依赖，已成功的登录也会在新进程中重新执行。自动登录使用 OPEN_GAME_APP_TASK 独立投影；收尾保留 DO_POST_ALL_TASK 原 flag，并依据上游按日去重的资源记录声明安全，不能把它们的数组位置错用于 TASK_ONOFF。平行数组投影绑定完整流水线及资源摘要。

源码入口按 adapter/sources.json 合并成仓外单脚本。没有文件、进程、网络或 native 对象旁路。原始 ZIP 的安装 Host 后端已验证四阶段协议、关闭旧进程族后保留必要登录的局部重试，以及主/附加配置接续与恢复。合成进程和日志不替代真实 BAAH；GUI worker 与新日志文件的归属、配置 UI 和真实发行二进制资格仍须独立验证。

实例启动、Android 与配置回写约束由 manifest 的 instancePolicy 声明，Host 保存和执行均校验同一声明。配置探测提供绑定源码身份的覆盖摘要；未知启用任务不视为完整覆盖。

日志声明匹配 `DATA/LOGS/log_*.txt`；关闭文件日志时可预览并应用受授权的精确修复。
