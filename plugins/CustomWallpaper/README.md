# 自定义壁纸

`custom-wallpaper` v0.1.8 使用 NexusPipeline Frontend API 1.2 提供设置页卡片。壁纸文件和外观配置由宿主保存到当前实例，所有浏览器通过 revision 轮询获得相同的顺序、随机轮换和显示参数。透明度设置可以单独控制二级弹出与浮层卡片的表面效果；切换轨道按钮卡片在宽度足够时直接显示完整说明。

宿主会校验图片类型、文件魔数、单文件 8192 KB 上限、32 张数量上限和 256 MiB 总容量，并在前端根据图片内容生成自适应强调色与主界面内容卡片表面色；启用壁纸后仍可使用宿主主题切换按钮。卡片与侧边栏透明度可在 0% 至 50% 之间调节，浅色、深色和跟随系统主题均保持有效。
