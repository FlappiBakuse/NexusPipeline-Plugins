# 游戏签到

`game-checkin` v0.3.0 提供独立签到任务。每个任务分别保存平台游戏选择、凭据、运行计划与通知设置，不依赖宿主用户或脚本运行。

支持的平台与游戏：

- 米游社：原神、崩坏：星穹铁道、绝区零、崩坏3
- HoYoLAB：Genshin Impact、Honkai: Star Rail、Zenless Zone Zero、Honkai Impact 3rd
- 森空岛：明日方舟、明日方舟：终末地
- SKPORT：Arknights: Endfield
- 库街区：鸣潮、战双帕弥什

任务可添加多个本机时区下的星期与 HH:mm 计划，也可手动执行。应用未运行时错过的时间不会补跑；每天每个平台游戏按凭据指纹去重，凭据变化后会按新账号执行。签到结果逐个平台持久化，页面显示最近运行记录。

每个任务都可以单独配置 Webhook 与 SMTP 通知。Webhook 支持通用 JSON 模板、飞书、钉钉、企业微信、Discord 和 Slack；SMTP 配置独立的服务器、发件人与收件人。任务凭据、Webhook URL/签名密钥和 SMTP 用户名/密码保存在任务专属 secret 中，读取接口仅返回是否已配置。

游戏签到需要有效的平台凭据；平台账号状态、验证码和风控可能影响结果。凭据与通知密钥不会写入插件日志或运行结果。
