# 游戏签到

`game-checkin` v0.4.2（需要 Host 0.17.2）提供独立签到任务。每个任务保存平台游戏选择、凭据、运行计划、备注和最近运行记录，不依赖宿主用户或脚本运行。

支持的平台与游戏：

网页登录的真实资格与未执行范围见[网页登录资格](docs/browser-login-readiness.md)。

米游社和库街区已实现固定字段采集与只读候选核验，等待真实账号验证。森空岛与 SKPORT 已补齐独立的只读通行证核验，原始 Token 的网页采集尚未支持；四个平台均保留手动配置。HoYoLAB 部分游戏可能要求手动完成验证码并停止本次签到，本版不处理验证码。

- 米游社：原神、崩坏：星穹铁道、绝区零、崩坏3
- HoYoLAB：Genshin Impact、Honkai: Star Rail、Zenless Zone Zero、Honkai Impact 3rd
- 森空岛：明日方舟、明日方舟：终末地
- SKPORT：Arknights: Endfield
- 库街区：鸣潮、战双帕弥什

任务可添加多个本机时区下的星期与 `HH:mm` 计划，也可手动执行。应用未运行时错过的时间不会补跑；每天每个平台游戏按凭据指纹去重，凭据变化后会按新账号执行。签到结果逐个平台持久化，页面显示最近运行记录。

签到通知使用宿主全局通知渠道。任务可单独开启通知，并可填写 SMTP 收件人覆盖值；留空时使用宿主全局收件人。SMTP 服务器、发件人和渠道开关由宿主管理。

v0.3.1 使用全新的任务存储格式，不导入 v0.3.0 的任务数据。游戏签到需要有效的平台凭据；平台账号状态、验证码和风控可能影响结果。凭据不会写入插件日志或运行结果。

手动凭据编辑时通过专用请求回读，默认遮罩。自动来源凭据在打开编辑器时不读取明文；点击眼睛后由本客户端主动确认，确认最长有效 24 小时，Host 重启或客户端会话失效后重新确认。其他客户端不继承确认。隐藏自动凭据会清除页面中的明文。

网页登录仅向可信本机 Electron 客户端开放已经真实验证的平台。平台状态由 `src/BrowserLogin/GameCheckInLoginFlows.cs` 维护；未就绪的平台保留手动输入。用户在官方页面登录后点击可信工具栏的“完成登录”，插件执行只读身份核验，窗口关闭并清理临时浏览器数据后显示脱敏账号及待保存候选；不会通过签到或领取奖励验证登录。每次登录使用新的临时会话。

登录成功只创建编辑器草稿，保存任务才替换持久凭据。已配置字段的占位提示显示脱敏身份与显示操作说明；清除按钮位于网页登录按钮右侧。只回读、显隐或修改名称不会重设凭据。清除只修改草稿，取消后原值保留，保存成功才删除该平台；自动值局部编辑仍为 `browser`，清空后重新手填变为 `manual`。来源和值以同一个版本化秘密记录保存，缺少记录头的合法旧值视为手动来源；损坏记录明确报错。

`POST tasks/credential/read` 接受当前客户端拥有的编辑会话、固定平台和字段代次；兼容手动凭据的任务级读取不允许读取自动来源。普通任务只投影是否配置、来源与脱敏元数据。后端候选绑定客户端、任务和字段代次；运行中保存返回 409，写入失败保留原秘密字节及可重用草稿，回滚失败或提交后响应失败报告结果未确认。明文不进入轮询、普通配置、日志或诊断，也不自动重发。
