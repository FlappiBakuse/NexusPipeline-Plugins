# 游戏签到

`game-checkin` v0.4.2（需要 Host 0.17.1） 提供独立签到任务。每个任务保存平台游戏选择、凭据、运行计划、备注和最近运行记录，不依赖宿主用户或脚本运行。

支持的平台与游戏：

- 米游社：原神、崩坏：星穹铁道、绝区零、崩坏3
- HoYoLAB：Genshin Impact、Honkai: Star Rail、Zenless Zone Zero、Honkai Impact 3rd
- 森空岛：明日方舟、明日方舟：终末地
- SKPORT：Arknights: Endfield
- 库街区：鸣潮、战双帕弥什

任务可添加多个本机时区下的星期与 `HH:mm` 计划，也可手动执行。应用未运行时错过的时间不会补跑；每天每个平台游戏按凭据指纹去重，凭据变化后会按新账号执行。签到结果逐个平台持久化，页面显示最近运行记录。

签到通知使用宿主全局通知渠道。任务可单独开启通知，并可填写 SMTP 收件人覆盖值；留空时使用宿主全局收件人。SMTP 服务器、发件人和渠道开关由宿主管理。

v0.3.1 使用全新的任务存储格式，不导入 v0.3.0 的任务数据。游戏签到需要有效的平台凭据；平台账号状态、验证码和风控可能影响结果。凭据不会写入插件日志或运行结果。

编辑已有任务时五个平台的已保存凭据通过专用请求回读，默认遮罩；眼睛仅切换显示。只回读、显隐或修改名称不会重设凭据。清除只修改草稿，取消后原值保留，保存成功才删除该平台；清除后重新输入保存为新值。读取失败可重试，正在保存阻止重复提交，运行中保存返回 409 而不取消签到。

`POST tasks/credential/read` 只接受 taskId 和固定 platform，返回 configured/value；任务普通视图只含配置布尔值。已配置但读取失败返回稳定错误，任务写入回滚失败或提交后返回失败报告结果未确认。明文不进入轮询、配置、日志或诊断，也不自动重发。
