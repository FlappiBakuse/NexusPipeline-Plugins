# 游戏签到

为多个游戏平台创建独立的签到任务，可立即执行或按计划运行。

当前版本 0.4.5，需要 NexusPipeline 0.17.2 或更高的兼容版本，运行环境为 Windows 11 x64。

## 开始使用

1. 在插件页面安装并启用插件，按提示重启 NexusPipeline。安装版本以插件页面为准；本文说明当前源码对应的功能。
2. 打开“游戏签到”，新建任务，选择平台与游戏。
3. 在本机桌面客户端点击对应平台的“网页登录”，在官方页面完成登录后点击窗口工具栏“完成登录”；塔吉多在任务编辑器的登录窗口中选择短信或密码登录。返回任务编辑器后保存，凭据才会生效。也可手动输入平台凭据。
4. 先手动执行并查看每款游戏的结果，再设置星期、时间及通知。

| 米游社 | 原神、崩坏：星穹铁道、绝区零、崩坏3 |
| HoYoLAB | Genshin Impact、Honkai: Star Rail、Zenless Zone Zero、Honkai Impact 3rd |
| 森空岛 | 明日方舟、明日方舟：终末地 |
| SKPORT | Arknights: Endfield |
| 库街区 | 鸣潮、战双帕弥什 |
| 塔吉多 | 异环 |

请在原官方社区页面完成登录，等待页面刷新完成并返回该页面后点击“完成登录”；额外第三方登录跳转可能不受支持。普通浏览器和远程客户端使用手动配置。

计划按电脑本地时区执行，应用关闭期间错过的计划不补跑。同一天同一平台游戏及凭据会去重。通知使用宿主全局渠道，任务可覆盖 SMTP 收件人。

每个任务的“运行记录”只展示最近一次签到的时间、状态和各游戏结果。切换到签到页面前先读取任务列表，准备期间保留原页面；快速切换取消尚未完成的读取，进入页面后才开始定期刷新。

## 常见问题

出现验证码或风控时，按官方页面提示人工处理；插件不会自动绕过验证码。HoYoLAB 部分游戏可能要求手动验证并停止本次签到。没有角色绑定、凭据过期或网络异常时，请查看结果并重新登录。

凭据默认遮罩；自动获取的凭据需主动确认后才显示，确认仅对当前客户端有效，最长 24 小时，Host 重启后重新确认。清除只修改草稿，保存任务才删除，取消编辑保留原值。网页登录核验不执行签到或领取奖励。

官方确认登录有效后，即使尚未绑定游戏角色也可保存凭据；执行任务时会提示对应游戏没有角色。森空岛网页登录需要同时读取该会话的设备信息，缺失时请重新登录。库街区网页登录凭据使用网页认证参数。必要的网页认证信息与凭据一起加密保存，不在明文回读中显示；修改凭据明文会清除对应的网页认证信息。

网页登录每次从平台固定首页开始。米游社、森空岛、SKPORT、库街区会尝试打开页头登录入口，HoYoLAB 保留网页自身的登录提示。自动打开失败时可手动操作；取消或关闭登录窗口保留旧凭据，真实凭据操作失败以 toast 提示。

## 塔吉多凭据

塔吉多使用原生登录返回的单行 JSON，包含 `accessToken`、`refreshToken`、`uid` 和 `deviceId`。现有网页登录 Cookie 不能替代原生凭据。点击“网页登录”可通过官方账号接口进行短信或密码登录并自动获取原生凭据，无需复制 JSON。手机号、密码和验证码不持久化；登录候选绑定当前客户端和编辑器，取消、关闭或过期均保留旧凭据，保存任务后才生效。也保留手动凭据入口。多个角色时额外填写 `roleId`，不自动选择不明确的角色。

运行时先刷新并加密保存凭据，再读取角色及今日签到状态。只有明确未签到才向异环游戏签到接口提交；提交后再次确认今日状态，无法确认时不记为成功。不执行社区金币、分享、云游戏或付费补签。签到状态确认不等同于独立核验游戏内奖励到账。
