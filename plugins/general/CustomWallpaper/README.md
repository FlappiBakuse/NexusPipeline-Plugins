# 自定义壁纸

设置主界面背景图片、轮换方式、明暗和透明度。

当前版本 0.3.4，需要 NexusPipeline 0.17.6 或更高的兼容版本，运行环境为 Windows 11 x64。

## 开始使用

1. 在插件页面安装并启用插件，按提示重启 NexusPipeline。安装版本以插件页面为准；本文说明当前源码对应的功能。
2. 在设置页面打开“自定义壁纸”，上传图片并选择当前壁纸。
3. 调整模糊、变暗、透明度与轮换方式；滑块释放后保存。

## 使用范围

最多 32 张图片，单张不超过 8192 KB，总容量不超过 256 MiB。相同内容的图片不会重复保存。卡片与侧边栏透明度范围为 0%–50%，支持浅色、深色及跟随系统主题。

按时间轮换在其他页面继续生效；按启动轮换由本机桌面会话触发，远程页面仅显示状态。关闭“透明度运用于非主页面”后，二级窗口与浮层使用不透明背景。

## 常见问题

上传失败时检查格式和容量。离开设置页面不会清空壁纸。旧版本外观文件保留在原目录，需要在新版本重新添加；插件不会自动导入旧文件。

上传取消或存储失败会清理本次新建资产；暂时无法清理的资产在下次启动重试。已经保存并仍被壁纸配置引用的图片始终保留。

清理记录格式未知或不完整时，插件保留原记录并停止初始化，避免误删图片或覆盖待处理信息。

排序把手采用紧凑横向占位，保留 40px 触控范围与键盘排序，卡片左右内边距保持一致。
