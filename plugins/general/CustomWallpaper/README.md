# 自定义壁纸

`custom-wallpaper` v0.3.1 使用 NexusPipeline Plugin API 2.1 与 Frontend API 1.6。壁纸配置、配额、文件头校验、SHA256 去重、排序、当前壁纸、时间和本机会话轮换、配色推导及 Web API 由插件实现。宿主提供通用插件资产存储、二进制 Web API 与外观表面；设置卡片使用公开 `nxp-*` 元素及 `--nx-*` design token。

运行时跟随插件前端模块。本机会话打开时推进一次 startup 轮换，远程会话只读取状态；进入或离开设置页面不会清除壁纸或改变当前壁纸，按时间轮换在任意页面继续生效。设置卡片遵循宿主统一的展开置顶规则，开关使用 `nxp-switch-list` 分组。

启用插件后，设置分类提供自定义壁纸入口。模糊、变暗及透明度滑块在拖动时即时显示数值，`change` 时保存；在途状态读取不会覆盖未提交的拖动值。关闭“透明度运用于非主页面”后，二级编辑窗口和浮层使用不透明表面，主页面卡片与侧边栏保持所设透明度。

插件校验图片类型、文件魔数、单文件 8192 KB 上限、32 张数量上限和 256 MiB 总容量，并根据图片内容生成强调色与主界面表面色。卡片和侧边栏透明度支持 0% 至 50%，浅色、深色及跟随系统主题均有效。

到点读取仍返回旧轮换投影时，每秒补读，单一过期时间最多八次，随后继续低频对账。相同 config revision 的新 timer 投影可被接受；确认保存或新的读取使旧请求失效，晚到的 GET 不回退当前背景。并发 start 共用初始化，dispose 取消计时并使未完成响应失效。旧代际外观文件与未知配置原字节保留，不自动导入。
