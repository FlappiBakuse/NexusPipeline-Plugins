# 实时截图窗口

在调度中心的运行任务卡片旁查看当前游戏或模拟器画面。

当前版本 0.3.2，需要 NexusPipeline 0.17.2 或更高的兼容版本，运行环境为 Windows 11 x64。

## 开始使用

1. 在插件页面安装并启用插件，按提示重启 NexusPipeline。安装版本以插件页面为准；本文说明当前源码对应的功能。
2. 在脚本及用户绑定中配置实际游戏或模拟器目标。
3. 启动队列，在运行任务卡片查看预览。任务结束后预览停止。

## 使用范围

PC 模式捕获已识别游戏窗口的客户区；安卓模拟器模式使用对应的模拟器驱动。预览保持原始宽高比，最高 360 像素，每五秒采样一次。它用于查看运行状态，不提供远程操作。

## 常见问题

没有画面时，先确认任务正在运行、游戏窗口可识别或模拟器连接正常。雷电、夜神和 BlueStacks 的专属支持需启用“模拟器支持扩展”。
