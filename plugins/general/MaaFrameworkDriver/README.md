# MaaFramework 框架直驱

直接读取 MaaFramework 项目的任务声明，在 NexusPipeline 中配置并运行任务。

当前版本 0.2.3，需要 NexusPipeline 0.17.3 或更高的兼容版本，运行环境为 Windows 11 x64。

## 开始使用

1. 在插件页面安装并启用插件，按提示重启 NexusPipeline。安装版本以插件页面为准；本文说明当前源码对应的功能。
2. 新建脚本并选择 MaaFramework 框架直驱，指定已准备好的项目根目录。
3. 自动读取已保存的 MXU、MFA 或 MaaPiCli 配置；多个来源时选择具体实例。仅在目标约束缺失或歧义时补齐必要设置。
4. 保存脚本，等待依赖准备、真实初始化及清理确认；ready 后才可加入队列。关闭编辑器可稍后查询同一保存进度。

## 使用范围

绑定的源配置变化后，在目标空闲时重新初始化并更新有效修订。用户绑定中的独立覆盖同样通过 Host 初始化后保存；共享配置更新后会重新套用用户修改，再初始化并发布用户修订。来源删除用户已修改的任务时保留旧配置并提示处理。不会自动迁移已有 MaaEnd、MaaStellaSora 专项脚本，也不会反向改写 GUI 配置。MaaStellaSora 1.6.0 的已知 Python Agent 组合支持固定依赖准备；未知依赖声明需要明确处理。

项目 Agent 和运行前任务会执行项目代码，进程隔离不提供文件系统或网络沙箱，请只授权信任的项目。项目代码、程序或资源变化后可能需要重新授权。

## 常见问题

窗口有多个匹配时，收紧完整 EXE 路径及窗口条件。运行库版本、架构或接口不匹配时不会执行；请使用项目要求的运行库。原生引擎完成不一定代表游戏业务成功，请结合任务历史和游戏结果检查。
