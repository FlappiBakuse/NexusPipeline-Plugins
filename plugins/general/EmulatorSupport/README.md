# 模拟器支持扩展

为 NexusPipeline 增加雷电、夜神和 BlueStacks 模拟器的识别、启动、截图及关闭支持。

当前版本 0.2.2，需要 NexusPipeline 0.17.2 或更高的兼容版本，运行环境为 Windows 11 x64。

## 开始使用

1. 先安装并启动一次所需模拟器，建立游戏实例。
2. 在插件页面安装并启用插件，按提示重启 NexusPipeline。安装版本以插件页面为准；本文说明当前源码对应的功能。
3. 在支持模拟器的脚本中选择模拟器启动方式，选择实际安装与实例，并在用户绑定中核对配置。

## 使用范围

只为支持模拟器启动的脚本提供运行能力，不会让 PC 专用脚本变成安卓脚本。Generic ADB 和 MuMuManager 已由宿主提供。多开时请明确选择实例，避免绑定错误设备。

## 常见问题

找不到实例时检查安装路径、厂商控制程序与实例是否可用，必要时先在模拟器自身启动一次。截图需要实际设备连接；插件安装成功不代表游戏已正确配置。
