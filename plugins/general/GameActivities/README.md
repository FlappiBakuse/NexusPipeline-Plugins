# 游戏活动

在主页面轮播所订阅游戏的本期活动版本，并查看单项活动。

活动卡默认显示在今日概览顶部。已保存的布局可通过“恢复默认”采用这一顺序，也可自行拖动调整。

当前版本 0.1.3，需要 NexusPipeline 0.17.2 或更高的兼容版本，运行环境为 Windows 11 x64。

## 开始使用

1. 在插件页面安装并启用插件，按提示重启 NexusPipeline。安装版本以插件页面为准；本文说明当前源码对应的功能。
2. 在主页面活动卡右上角点击 ⚙️，选择游戏、区服、顺序与轮播间隔并保存。默认没有订阅。
3. 主卡显示版本名称、封面、本期截止时间与倒计时；点击卡片查看活动。底部浅灰横线可直接切换游戏；右上角 缩放图标 在原比例与 16:9 间切换并以动画调整高度，⏸️／▶️ 暂停或恢复轮播，🔄 手动刷新。窄屏保留最低可读高度；系统开启减少动态效果时直接切换。

## 使用范围

支持蔚蓝档案国服／日服／国际服，原神、明日方舟：终末地、星塔旅人、崩坏：星穹铁道、鸣潮、绝区零，以及异环国服／国际服。活动由 SRA 提供，语言跟随区服来源。

详情按进行中、即将开始、已结束和时间未知分组；已结束默认折叠。详情显示活动原文、起止时间和可用封面。时间转换为电脑时区，无法确认的时间显示未知。活动列表不包含卡池，也不提供公告跳转。

## 常见问题

每六小时自动检查，并在活动时间边界附近检查。手动刷新每分钟最多一次。网络异常时显示上次成功的缓存；首次获取失败时可稍后重试。更新成功后用新的活动列表替换旧列表，不保留消失的活动。

图片稍后加载或没有图片不影响文字。若一直无图，可尝试刷新；插件只使用来源提供且通过校验的图片，不搜索替代图片。

活动设置使用固定底部的取消/保存操作。全部游戏均可拖拽排序，未订阅游戏的顺序也会保存；只有一个订阅时隐藏左右翻页按钮。

局域网 HTTP 访问可直接查看活动详情；图片分组由当前资源会话分配独立标识，不依赖安全上下文 API。缩放按钮使用矢量图标，窄屏不依赖字体字形。
